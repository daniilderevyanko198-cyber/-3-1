
## 🚀 Возможности

- 🎮 **Интуитивное управление** — клавиши стрелок для движения
- 📊 **Система счёта** — +10 очков за каждую съеденную еду
- ⚡ **Динамическая сложность** — скорость увеличивается каждые 50 очков
- ⏸️ **Пауза** — возможность приостановить игру в любой момент
- 🔄 **Быстрый перезапуск** — нажмите R для новой игры
- 🎨 **Красивая графика**:
  - Закруглённые сегменты змейки
  - Глаза у головы змейки
  - Сетка игрового поля
  - Приятная цветовая гамма (тёмная тема)
- 💀 **Game Over с предложением переиграть**
- 📏 **Адаптивный размер окна** — окно центрируется на экране

## 🕹️ Управление

| Клавиша | Действие |
|---------|----------|
| `←` | Движение влево |
| `→` | Движение вправо |
| `↑` | Движение вверх |
| `↓` | Движение вниз |
| `P` | Пауза / Продолжить |
| `R` | Новая игра |
| `ESC` | Выход из игры |

## 🎯 Правила игры

1. Управляйте змейкой с помощью клавиш-стрелок
2. Собирайте красную еду (🍎) для увеличения счёта и длины
3. Каждая съеденная еда приносит **10 очков**
4. Змейка не может:
   - Врезаться в стены игрового поля
   - Врезаться в собственное тело
5. Игра ускоряется каждые **50 очков** (максимальная скорость достигается к 500+ очкам)
6. Игра продолжается до первого столкновения
