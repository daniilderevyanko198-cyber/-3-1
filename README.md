
## 🚀 Возможности

- 🖥️ **Полноэкранный режим** — игра занимает весь экран
- 🎯 **Умный ИИ** — компьютер пытается выиграть и блокирует ваши ходы
- 🎨 **Современный дизайн** — приятная цветовая гамма и анимация
- 🔄 **Быстрый перезапуск** — кнопка «Новая игра» или клавиша
- 🏆 **Подсветка победы** — выигрышная линия подсвечивается жёлтым
- 📱 **Адаптивный интерфейс** — подстраивается под разрешение экрана
- ⌨️ **Управление с клавиатуры** — поддержка горячих клавиш

## 🕹️ Управление

| Действие | Способ |
|----------|--------|
| Сделать ход | Клик мышью по клетке |
| Новая игра | Кнопка «НОВАЯ ИГРА» |
| Выход из полноэкранного режима | Клавиша `ESC` |
| Закрыть игру | `Alt+F4` или крестик окна |

## 🧠 Уровень сложности ИИ

Компьютер использует следующую стратегию (в порядке приоритета):

1. **Выигрыш** — если может победить, ходит туда
2. **Блокировка** — если вы можете победить, блокирует ваш ход
3. **Центр** — занимает центральную клетку
4. **Углы** — занимает свободный угол
5. **Случайный ход** — любой свободной клеткой
